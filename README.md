## Who this is for

Anyone preparing for the BSCP, juniors especially. If you've done a few Web Security Academy labs and you're staring at the exam wondering what it actually expects, this is for you. It won't teach you web security from zero, but it will save you the time and the avoidable mistakes I didn't save myself.

## What this is, and what it isn't

This is a preparation guide built from my own experience. It covers scope, methodology, tooling and exam-day logistics. It does **not** contain any exam content or solutions, in line with PortSwigger's rules. Everything here applies to the free, public [Web Security Academy](https://portswigger.net/web-security) and to web targets you own or are authorised to test.

The whole point is to lean on the things you can't get from a payload list: how to recognise a vulnerability fast, how to scope your study, and how to set up so the exam doesn't catch you off guard.
